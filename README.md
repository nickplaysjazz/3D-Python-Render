## 3D Python Render
A simple 3D rendering tool built in PyGame using PyOpenGL for graphics.


## Installation & Setup
If you are using the `uv` python package manager (recommended; handles Python versions and dependencies automatically): 
- Install and run the program with `uv run python main.py`.

If you are using the `pip` python package manager:
- Create a new virtual environment `render` with `python -m venv render`. 
- Activate the virtual environment with `source render/bin/activate` on macOS / Linux or `render\Scripts\activate` on Windows Command Prompt / PowerShell. 
- Install dependencies with `pip install -e .`.
- Run the program with `python main.py`.

If you are using the `conda` or `mamba` python package manager:
- Create a new virtual environment `render` with `conda create -n render python=3.11 -y`.
- Activate the virtual environment with `conda activate render`.
- Install dependencies with `pip install -e .`.
- Run the program with `python main.py`.
